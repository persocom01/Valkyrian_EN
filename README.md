# Valkyrian_EN
The repository for the English translation of the Chinese Starsector mod, Valkyrian.

I did not make this mod. All rights go to the authors, ValkyriaL and Originem.

Original fossic post: https://www.fossic.org/forum.php?mod=viewthread&tid=630

Can be swapped between EN and CN versions by running the swap_CN_EN.py file.
